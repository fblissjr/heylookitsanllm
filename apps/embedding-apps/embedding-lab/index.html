Embedding Lab

Measure how well a model, engine, dimension size and task prompt retrieve the right thing. You supply cases (a query, what should match, what should not); the Lab ranks every case's query against all documents and compares configurations side by side.

1. Test set

A folder holding set.json and any media it names. Try embedding-lab/sample/.
set.json format 
{ "cases": [
  { "id": "optional-unique-name",
    "query": "text" | { "text": "...", "file": "a.png" },
    "positives": [ "text" | { "file": "a.png" } ],
    "negatives": [ ... ] } ] }

Items are text, a file, or both. Files are paths inside the chosen folder. Every document from every case forms one pool, so a case also competes against the other cases' documents.
